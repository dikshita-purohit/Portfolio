The Vision

Nightfang: Vampire Hunt is a fast-paced 2D vampire shooter built entirely in Unity with C#. The game features responsive player controls, custom enemy AI, collectibles, a scoring system, UI management, and polished collision detection — all hand-coded to deliver smooth and satisfying player-enemy interactions. Every system from shooting mechanics to swarm AI was designed to create an engaging, replayable combat experience set in a dark gothic world.

Project Features

Shooting System

Hand-coded projectile system with directional aiming, hit detection, and real-time score triggers on every enemy kill.

Enemy AI Behavior

Custom C# behavior trees power enemy chase, flanking, swarm cohesion, and retreat logic for dynamic and reactive combat.

Scoring, UI & Collectibles

Full scoring pipeline with collectibles, HUD, health bars, and game-state screens — all managed via C# UI controllers.

Gameplay Architecture

PLAYER INPUT

Responsive controls capture player movement and aim direction, feeding into the shooting and collision systems every frame.

SHOOTING & COLLISION

Projectiles are spawned, tracked, and checked against enemy hitboxes each frame — triggering damage, death animations, and score updates on contact.

ENEMY AI

Behavior trees evaluate player position and health each tick — switching enemies between aggro, flanking, swarm, and retreat states in real time.

SCORING & UI

Score, collectibles, and health update the HUD in real time. Game-state managers handle pause, win, and lose screens through C# UI controllers.
