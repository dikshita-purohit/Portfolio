The Vision

Symphony of Drops is a dynamic, fast-paced 2D touch-based arcade game engineered specifically for Android mobile devices. Built in Unity with C#, the game implements precise mobile input registers, fluid physics-driven object spawner mechanics, custom scoring logic, and responsive multi-touch components. Every layer of the game is hand-crafted to process seamless casual touch controls, real-time kinetic collision tracking, and smooth mobile UI animations, providing an immersive fluid melody experience.

Gameplay Architecture

MOBILE TOUCH HANDLER

Integrated touch phases collect Screen coordinate matrices directly, transforming screen inputs into global game vector coordinates instantly.

KINETIC PHYSICS & DROPS

Falling droplets utilize Unity 2D gravity states, interacting with screen bounds and trigger boxes to calculate accurate hits and miss conditions.

SPAWNER ENGINE

Automated procedural routines handle instantiations, regulating drop tempos, variances, and spatial arrangements incrementally to expand difficulties.

ARCADE SCORE PIPELINE

Real-time point scoring logic updates live metrics, modifying combo multipliers and screen HUD nodes natively via lightweight events.
