The Vision

3D Wildlife AR is an AI-powered augmented reality mobile application built with Unity, YOLOv11, Python, and cloud-based services. The app captures real-world camera images, detects animal species using a custom-trained deep learning model, and overlays interactive 3D animal models directly into the user's environment via AR. By combining computer vision, real-time object detection, cloud AI inference via Azure, and Gemini AI for species data, it delivers an educational and immersive wildlife exploration experience.

Project Features

A full-stack AI + AR pipeline — from camera capture to real-time 3D animal visualization, all processed through cloud inference.

Real-Time Animal Detection

Custom-trained YOLOv11 model identifies wildlife species from live camera frames with high accuracy and low latency.

Interactive 3D AR Models

Animated 3D wildlife models are rendered in the user's real environment via Unity AR Foundation with touch interaction support.

Cloud AI + Gemini Integration

Azure endpoints with VS Code port forwarding enable seamless cloud inference. Gemini AI delivers real-time species facts and ecological data.

AI Workflow Architecture

IMAGE CAPTURE

The Unity mobile app captures live camera frames and sends them via HTTP to the cloud AI server for processing.

YOLO + CLOUD INFERENCE

A Python backend on Azure runs the YOLOv11 model, detects species, and queries Gemini AI for species data — results returned as JSON.

DATA DELIVERY

Detection results and species metadata are sent back to the Unity app via Azure endpoints, forwarded through VS Code port forwarding.

AR VISUALIZATION

The detected animal is matched to its 3D model and rendered in AR using Unity AR Foundation, with real-time species info overlays.
